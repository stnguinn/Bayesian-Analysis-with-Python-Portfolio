# Bayesian-Analysis-with-Python-Portfolio
Professional Focus

This repository is designed to strengthen applied Bayesian analysis skills for data analytics, decision science, experimentation, forecasting, and business intelligence work. The emphasis is not only on coding models, but also on interpreting uncertainty and explaining results in a way that supports better decisions.

The main goals of this repository are to:

- Development of my of Bayesian statistics analysis.
- Build probabilistic models in Python using PyMC.
- Use ArviZ to summarize, diagnose, and communicate Bayesian models.
- Apply prior predictive checks, posterior summaries, and posterior predictive checks.
- Build Bayesian regression, hierarchical models, mixture models, Gaussian processes, and BART models.
- Compare models using Bayesian workflow tools such as LOO, posterior predictive checks, and Bayes factors.
- Create portfolio-ready Bayesian analysis projects with clear business and statistical interpretation.

## Core Topics Covered

This repository will gradually cover the following topics:

1. Thinking probabilistically
2. Probability distributions and Bayesian inference
3. Priors, likelihoods, and posterior distributions
4. PyMC probabilistic programming
5. ArviZ posterior analysis and visualization
6. Highest Density Intervals and posterior summaries
7. Posterior predictive checks
8. Bayesian decision-making and loss functions
9. Robust Bayesian models
10. Hierarchical models
11. Bayesian linear and generalized linear regression
12. Bayesian model comparison
13. Bambi for Bayesian regression modeling
14. Variable selection with Kulprit
15. Mixture models
16. Gaussian processes
17. Bayesian Additive Regression Trees
18. MCMC diagnostics and inference engines
